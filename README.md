# AO3 Scraper (MVP)

## Description
Old prototype automation tool built with Python for collecting fanfiction works from AO3 via Selenium and BeautifulSoup.

The goal of the project is to create personal archives of works using a provided URL.

## Tech
- Python
- Selenium
- BeautifulSoup

## Features
- Browser automation for page loading
- Data extraction from AO3 pages
- Basic content saving for local archive creation

## Note
This is an early-stage MVP project created for learning purposes and experimentation with web scraping and browser automation.
